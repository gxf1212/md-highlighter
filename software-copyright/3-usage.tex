\section{使用示例}

\subsection{NAMD/CHARMM 文件格式}

\subsubsection{蛋白质数据库文件（PDB）}

PDB 文件的高亮规则定义在 \lstinline|syntaxes/pdb.tmLanguage.json|。相关规则先将 \lstinline|CRYST|、\lstinline|REMARK|、\lstinline|HEADER|、\lstinline|TITLE|、\lstinline|COMPND|、\lstinline|SOURCE|、\lstinline|JRNL|、\lstinline|CONECT| 等记录作为说明性记录处理；再单独匹配 \lstinline|CRYST1|、\lstinline|TER|、\lstinline|END|、\lstinline|HELIX|、\lstinline|SHEET|、\lstinline|SSBOND|；对 \lstinline|ATOM| 和 \lstinline|HETATM| 行，则按固定列宽继续拆出原子序号、原子名、残基名、链标识、残基编号、坐标、占有率、温度因子、段名、电荷等字段。
如\ref{fig:pdb-highlighting}所示，PDB 文件中的记录头和原子数据列在编辑器中已有分层显示。

\begin{figure}[!h]
    \centering
    \includegraphics[width=0.85\textwidth]{../images/pdb.png}
    \caption{PDB 文件语法高亮演示（.pdb 格式）}
    \label{fig:pdb-highlighting}
\end{figure}

记录名与数据行分别处理；原子记录内部又按固定列位置区分原子序号、原子名、残基名、链ID、三列坐标和元素符号等字段。该规则用于在编辑器中查看文本布局，并核对坐标列、残基编号和记录类型。

\subsubsection{残基拓扑文件（RTF）}

RTF 和部分 CHARMM 参数文件共用 \lstinline|syntaxes/rtf.tmLanguage.json|。相关语法文件同时包含拓扑项和参数项。实际匹配内容包括以 \lstinline|!| 和 \lstinline|*| 开头的注释行，\lstinline|MASS|、\lstinline|RESI|、\lstinline|PRES|、\lstinline|ATOM|、\lstinline|BOND|、\lstinline|ANGLE|、\lstinline|DIHEDRAL|、\lstinline|IMPR|、\lstinline|PATCH|、\lstinline|LONEPAIR| 等关键字，以及这些关键字后面的质量编号、元素符号、残基名、电荷数值、原子名称和原子类型。
如\ref{fig:rtf-highlighting}所示，注释、关键字和参数列已经区分开。

\begin{figure}[!h]
    \centering
    \includegraphics[width=0.85\textwidth]{../images/rtf.png}
    \caption{RTF 文件语法高亮演示（.rtf 格式）}
    \label{fig:rtf-highlighting}
\end{figure}

在该文件中，注释、拓扑关键字、残基名、电荷、原子名和参数区数据分别显示；\lstinline|MASS|行以及\lstinline|RESI/PRES|行还有单独规则。该类高亮用于查看残基定义、键接关系以及力场项的文本组织方式，并定位拓扑段落。

\subsubsection{蛋白质结构文件（PSF）}

PSF 文件的高亮规则定义在 \lstinline|syntaxes/psf.tmLanguage.json|。该规则重点区分 \lstinline|PSF| 文件头、说明性记录、各个分段标题、总数值以及原子数据行中的字段。对于长文件而言，分段标题和数据主体分别显示。
如\ref{fig:psf-highlighting}所示，PSF 文件中标题区、分段标识和正文数据区分开显示。

\begin{figure}[!h]
    \centering
    \includegraphics[width=0.85\textwidth]{../images/psf.png}
    \caption{PSF 文件语法高亮演示（.psf 格式）}
    \label{fig:psf-highlighting}
\end{figure}

其实现方式较为明确，文件头、分段标识、计数字段和原子相关数据采用不同作用域。对较长的PSF文本而言，可区分分段标题和数据区域。

\subsubsection{CHARMM 参数文件（PRM）}

扩展把 \lstinline|.prm| 文件也归入 \lstinline|rtf| 语言配置，因此它的语法高亮仍然来自 \lstinline|syntaxes/rtf.tmLanguage.json|。在该分析项中，主要是对 \lstinline|BONDS|、\lstinline|ANGLES|、\lstinline|DIHEDRALS|、\lstinline|IMPROPERS|、\lstinline|CMAP|、\lstinline|NONBONDED|、\lstinline|NBFIX| 等参数区名称做匹配，再把原子类型、浮点数参数和部分节标题分开显示。
如\ref{fig:prm-highlighting}所示，参数区标题与数值列已形成层次。

\begin{figure}[!h]
    \centering
    \includegraphics[width=0.85\textwidth]{../images/prm.png}
    \caption{CHARMM PRM 参数文件语法高亮演示（.prm 格式）}
    \label{fig:prm-highlighting}
\end{figure}

PRM 部分主要区分参数区标题、原子类型字符串和数值参数。其作用主要体现在阅读和修改参数文本时，对节标题、类型名和数值列进行分层显示。

\subsection{Amber/AmberTools 文件格式}

\subsubsection{Amber 拓扑文件（PRMTOP）}

PRMTOP 文件使用 \lstinline|syntaxes/prmtop.tmLanguage.json|。相关规则按块编写，先识别 \lstinline|%VERSION|、\lstinline|%FLAG|、\lstinline|%FORMAT| 三类标记，再对 \lstinline|ATOM_NAME|、\lstinline|ATOMIC_NUMBER|、\lstinline|MASS|、\lstinline|RESIDUE_LABEL|、\lstinline|AMBER_ATOM_TYPE| 等数据块分别处理。实际输出中，格式字符串、原子名、原子序数、残基名、原子类型和数值项落在不同作用域里。
如\ref{fig:prmtop-highlighting}所示，PRMTOP文件在编辑器中更接近按块阅读的效果。

\begin{figure}[!h]
    \centering
    \includegraphics[width=0.85\textwidth]{../images/prmtop.png}
    \caption{Amber PRMTOP 文件语法高亮演示（.prmtop 格式）}
    \label{fig:prmtop-highlighting}
\end{figure}

实际显示时，\lstinline|%FLAG|/\lstinline|%FORMAT|标记、格式说明、原子名块、残基标签块和数值块会被分层处理。对PRMTOP这类按块组织的数据文件而言，可据此定位常见分段。

\lstinline|.parm7|扩展名在\lstinline|package.json|中与\lstinline|prmtop|语言ID共用同一套语法定义，因此它的高亮方式和PRMTOP相同。没有为\lstinline|.parm7|另外再写一套规则，而是直接复用\lstinline|syntaxes/prmtop.tmLanguage.json|中的分块匹配逻辑。
如\ref{fig:parm7-highlighting}所示，PARM7文件的显示层次与PRMTOP基本一致。

\begin{figure}[!h]
    \centering

    \caption{Amber PARM7 文件语法高亮演示（.parm7 格式）}
    \label{fig:parm7-highlighting}

由于直接复用了PRMTOP的规则，因此这里采用的也是同一套标记、字段块和数值高亮方式。对应的文件范围为使用\lstinline|.parm7|扩展名的Amber拓扑文件。

\subsubsection{Amber 库文件（LIB）}

LIB/OFF 文件的语法定义位于 \lstinline|syntaxes/lib.tmLanguage.json|。相关规则基本按照文件本身的组织方式编写，主要识别 \lstinline|!entry| 记录、残基名、unit 类型、原子名、残基编号、原子编号、元素编号、电荷以及纯数字索引行。以 \lstinline|!entry| 开头的结构段单独处理，因此头部标识和后续数据行不会处于同一层级。
如\ref{fig:lib-highlighting}所示，LIB文件中的条目头和原子数据区已区分开。

\lstinline|!entry|关键字、残基名、原子名、编号和电荷字段分别显示。查看tLeap库文件时，可按条目结构逐段阅读，并定位原子列表。

\subsubsection{Amber 预处理输入文件（PREPIN）}

PREPIN 文件的规则定义在 \lstinline|syntaxes/prepin.tmLanguage.json|。除原子表外，该规则还包含若干控制项，识别 \lstinline|remark| 信息行、\lstinline|DU/ DUM| 占位原子、坐标类型 \lstinline|INT|/\lstinline|XYZ|、\lstinline|CORRECT|、\lstinline|CHANGE|、\lstinline|OMIT|、\lstinline|LOOP|、\lstinline|IMPROPER|、\lstinline|DONE|、\lstinline|STOP| 等控制关键字，以及原子编号、原子名、原子类型、树符号、电荷和浮点数。
如\ref{fig:prepin-highlighting}所示，说明段、控制项和原子表在显示上已有区分。

说明行、控制关键字、原子信息列和电荷数值在当前版本中均有对应匹配。对于非标准残基预处理文件，该类分段可用于人工核对原子表和控制段。

\subsection{Gromacs 文件格式}

\subsubsection{Gromacs 坐标文件（GRO）}

GRO 文件的高亮规则定义在 \lstinline|syntaxes/gro.tmLanguage.json|。相关规则按列宽处理：时间步字符串、标题行、总原子数行、盒子向量行先行区分，正文再按固定列宽区分残基编号、残基名、原子名、坐标列和速度列。代码中预留了原子编号字段的位置，但该项当前的\lstinline|match|为空，因此现阶段重点仍是名称列和数值列。
如\ref{fig:gro-highlighting}所示，GRO文件的列结构在编辑器中已显示出来。

\begin{figure}[!h]
    \centering
    \includegraphics[width=0.8\textwidth]{../images/gro.png}

标题、总数、盒子向量、残基名、原子名、坐标和速度列在显示上分别区分。GRO文件本身依赖列结构，因此这类高亮主要围绕列结构展开。

\subsubsection{Gromacs 原子类型文件（ATP）}

ATP 文件使用 \lstinline|syntaxes/atp.tmLanguage.json|。该规则内容较短，主要处理分号注释、浮点数、一般原子类型字符串以及带 \lstinline|amber| 前缀的类型名。
如\ref{fig:atp-highlighting}所示，ATP文件里类型名和数值列已区分开。

    \label{fig:atp-highlighting}
\end{figure}

ATP 部分层级较少，主要区分注释、类型名和参数数值。用于查看原子类型表和对应参数时，可先看名称列，再看数值列。

\subsubsection{Gromacs 原子重命名文件（ARN）}

ARN 文件的语法定义位于 \lstinline|syntaxes/arn.tmLanguage.json|。其识别分号注释、浮点数、行首的残基名、其后的原子名以及后续原子类型字符串。该文件属于映射类文本，实现重点在于区分名称列和数值列。

ARN 文件中，注释、残基名、原子名和原子类型字符串分别匹配。该写法用于人工检查重命名规则文本中的字段顺序。

\subsubsection{Gromacs 残基类型文件（RTP）}

RTP 文件使用 \lstinline|syntaxes/rtp.tmLanguage.json|。规则里识别分号注释、\lstinline|torsion|和\lstinline|un|等特殊说明行、方括号分段名、原子名、四元原子组、原子类型、电荷以及一般数值项。像\lstinline|[ atoms ]|、\lstinline|[ bonds ]|、\lstinline|[ impropers ]|这些分段内常见字段，当前都做了区分。

RTP 中的层次划分较为清楚：分段名称、原子组、原子类型、电荷和数值参数分别显示。编辑或阅读RTP文本时，可先定位分段，再查看字段列。

\subsubsection{Gromacs 氢数据库文件（HDB）}

HDB 文件的语法定义位于 \lstinline|syntaxes/hdb.tmLanguage.json|。规则识别分号注释、行首残基名、数量字段、原子名组以及数值项。HDB 的文本组织较为规整，因此主要依靠列位置和行结构进行匹配。

HDB 里，残基名、计数字段、原子名组合和数值列是分别显示的。对这类加氢规则文件来说，可据此查看条目结构。

\subsubsection{Gromacs 残基到珠映射文件（R2B）}

R2B 文件使用 \lstinline|syntaxes/r2b.tmLanguage.json|。实现较简单，主要对分号注释、字符串形式的残基名以及数值项进行区分。

R2B 的高亮规则较为简洁，注释、名称字段和数值字段分别显示，更接近轻量级映射表的展示方式。

\subsubsection{Gromacs 突变拓扑文件（MTP）}

MTP 当前能够区分默认关键字、分段、原子名、电荷和数值列。阅读突变拓扑文本时，可先定位状态块，再查看原子字段。

\subsubsection{Gromacs 虚拟位点定义文件（VSD）}

VSD 文件的语法定义位于 \lstinline|syntaxes/vsd.tmLanguage.json|。这是0.0.7版本新增支持的文件类型。规则识别分号注释、关键字\lstinline|planar|、方括号分段、原子名、原子类型和数值项，范围不大，但和当前代码是一致的。

VSD 部分的范围较小，关键字、分段、原子名和参数值分别显示。用于查看虚拟位点定义文本中的名称列和参数列已能满足当前需要。

\subsection{小分子文件格式}

\subsubsection{MOL2 分子结构文件（MOL2）}

MOL2 文件使用 \lstinline|syntaxes/mol2.tmLanguage.json|。该语法与前面几类文件不同，实际通过 \lstinline|repository.structure| 中的规则工作。当前可识别注释行、以 \lstinline|@<TRIPOS>| 形式出现的结构段标识、原子编号、原子名、原子类型、残基编号、残基名、电荷和键类型。由于使用了 \lstinline|include| 引用内部仓库规则，因此文件结构与其他语法文件并不完全一致。
如\ref{fig:mol2-sdf-highlighting}所示，其中(a)为MOL2文件显示效果，(b)为SDF文件显示效果。

MOL2 中，结构段标识、原子名、原子类型、残基信息、电荷和键类型分别显示。该格式用于阅读小分子结构文本中的原子表和键表。

\section{总结}

md-highlighter 当前版本面向分子动力学相关文本文件的编辑器级语法高亮。源码中已注册23个语言ID，并配套23个语法定义文件，不包含独立计算引擎、网络服务或数据库模块。

\subsection{实际用途：文本阅读和人工检查}

本软件的直接用途在于文本阅读和编辑辅助。对于列宽固定或字段密集的文件，语法高亮用于区分不同字段所在位置。例如：
\begin{itemize}
    \item PDB、GRO、AC这类固定列宽文件中，坐标列和名称列可分开查看
    \item PRMTOP、LIB、TDB、RTP这类分块或分段文件中，可先定位分段标识
    \item tleap、PLUMED等脚本文件中，命令和参数名可按不同颜色层次查看
\end{itemize}

“检查”指人工阅读时的辅助，不等同于程序自动校验，也不表示软件能够给出结构正确性结论。

\subsection{未来发展}

后续仍有一些可继续完善的方向：
\begin{itemize}
    \item 继续补充更多分子模拟相关文本格式，如LAMMPS软件等
    \item 调整部分规则对特殊原子命名方式的兼容性
    \item 针对已有语法文件中的已知问题继续细化匹配范围
    \item 结合实际使用情况修正少数过宽或过窄的正则规则
\end{itemize}
